This repository have all my C++ learn files

if you want to try any files from this follow steps in your terminal:

**Step1 :** check you are have the C++ compiler in your OS by:
```
g++ --version
gcc --version
gdb --version
```
if output have a number of version you are ok!

**Step2 :** Download the file you want to try

**Step3 :** compile this file by:
```
g++ -g files.cpp -o file
```
And replace "file" in line with name of file you want

**Step4 :** run the file with
```
./file
```

**NOTE :** All this steps will work only in liunx if you are Windows or MacOS you should to use the best way for it or install linux terminal in your system
